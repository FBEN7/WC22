# M6 — Synthèse

## Trois constats

1. Les contrôles M1 trouvent deux timestamps défectueux dans la finale France–Argentine et cinq périodes de poste anormales parmi les fixtures.
2. Le PPDA varie d'environ 9,92 pour l'Argentine à 25,43 pour l'Iran dans les trois matchs fixtures. Ce n'est pas une mesure globale de qualité défensive : plus PPDA signifie plus de passes admises avant une action défensive retenue.
3. Les données complètes permettent de mesurer le xG : distance/angle obtient 0,300 de log loss contre 0,282 pour le modèle avec freeze-frame et 0,267 pour StatsBomb.

## Limites

Les findings locaux restent petits. Les notes M2/M4 sur les trois fixtures ne remplacent pas une analyse sur les 64 matchs disponibles. Le test M3 complet est passé, mais son tableau détaillé doit être repris sur les trois tournois complets. Data : StatsBomb Open Data, attribution requise.
