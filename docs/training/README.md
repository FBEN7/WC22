# Training material

This project started as a structured self-training brief for a football data analyst role
at a data provider: build the warehouse, then data-quality checks (M1), analytical SQL
(M2), an xG model (M3), expected threat (M4) and a Streamlit app (M5).

- [BRIEF.md](BRIEF.md): the original brief (in French).
- [notes/](notes/): milestone notes written along the way.

Those components are now the toolkit behind the main analysis in the
[README](../../README.md).
